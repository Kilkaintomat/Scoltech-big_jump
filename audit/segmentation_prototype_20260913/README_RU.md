# Прототип сегментации Lean

Главный файл для чтения — REPORT_RU.html. Он работает без сети и содержит просмотр дерева.
REPORT_RU.md — текст отчёта; statistics.json и block-counts.csv — полная статистика длин.

Рабочая копия на Жоресе:
  /beegfs/home/denis.rakhmankin/onebigjump/audit/segmentation_prototype_20260913

segmenter.py + syntax_command.lean — конечный прототип.
Для одного примера, внутри подготовленного окружения Slurm:
  python segmenter.py example-input.json --output example-result.json --replay

Нужны окружение проекта onebigjump, Lean v4.34.0-rc2, закреплённый REPL и Mathlib.
Скрипты *.sbatch показывают контейнерное окружение и staging Lean. Не запускать вычисления
на login-узле или локально. Перед повтором скопировать этот каталог в новый audit-каталог
и поправить абсолютные пути batch-скриптов, чтобы сохранить имеющиеся результаты.

Прототип принимает header (оканчивается на by) и неизменённый body.
Необязательные completion и body_start позволяют проверить точный перенос координат
в исходный ответ модели. Активации модели не извлекаются.

validation/ — сырые живые ответы первого малого запуска; live-code/ хранит его исходники.
В начальных метриках ошибок было недостаточно учтено: использовать review/metrics.json,
а не первоначальные счётчики успешных повторов.
review/ — окончательная классификация тех же ответов и проверка строгого переноса координат.
validation_supplement/ — три дополнительных живых проверки после исправления ошибок.
protocol-review.json — шесть проверок конечной обработки ответов REPL.
Поле label_ready остаётся false: этот прототип не заменяет основной проверяющий конвейер.

Известные ограничения:
- Частичное AST при синтаксической ошибке не поддержано.
- calc, cases … with и некоторые управляющие комбинаторы остаются атомарными.
- Снимки составных тактик выдаются не для всех узлов.
- Снимки из InfoTree иногда не содержат всех зависимостей для завершения проверки kernel.
  Такой отказ получает snapshot_kernel_rejection и не считается ошибкой модели.
- Локальные цели не равны глобальному состоянию доказательства.
- Итоговая разметка pre/at/post и post_completion требует дополнительного адаптера.
- Границы токенов проверены только на небольшом синтетическом отображении; реальные
  сохранённые token_ids трёх моделей не обрабатывались.
- Ограниченный повтор в сохранённых контекстах не является полной последовательной трассой.
