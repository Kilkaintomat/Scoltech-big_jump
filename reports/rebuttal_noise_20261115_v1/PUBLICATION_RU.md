# Приватная публикация

Пользователь отдельно разрешил загрузить отчёт на GitHub и потребовал сделать репозиторий закрытым. Видимость репозитория изменена на private до загрузки этой серии.

Исходные результаты, протокол и манифесты на вычислительном сервере сохранены. В этой копии заменены инфраструктурные пути и названия. Численные метрики, таблицы и графики не пересчитывались. Исторические фразы об отсутствии публичной публикации остаются верными: репозиторий приватный.

Файл manifest.json — манифест научного расчёта с заменёнными инфраструктурными путями. Его хеши относятся к исходным артефактам. Файл publication_manifest.json отдельно связывает каждый исходный файл с байтами копии на GitHub; для файлов с заменами хеши закономерно различаются. Зафиксированный protocol.md сохранён побайтно.

При запуске репозиторных проверок uv вне контейнера пересоздал окружение .venvc. Оно восстановлено внутри прежнего контейнера; совпадение исходников использовавшихся библиотек проверено по сохранённым хешам. [Повторная проверка целостности](audit_integrity_post_recovery.json) и [запись восстановления](environment_recovery/restored.json) сохранены рядом. Вспомогательные модельные зависимости восстановлены по проектному uv.lock: полного исходного pip freeze не было. Генерация моделей не выполнялась.

Крупные состояния и коэффициенты моделей остаются в исходном хранилище. Для этой публикации не запускались новые эксперименты и не менялись обучающие/оценочные разбиения.
