# Уточнение реализации N9 — 2026-11-15 UTC, до supervised fits
Для miniF2F сохранены полные приращения всех3 моделей. N9b расширяется и на эти3 ячейки. Историческая матрица локализаторов не содержит соответствующих miniF2F outer/inner разбиений; используем детерминированный GroupKFold5/3 с тем же принципом группировки, сохраняем разбиения. ProofNet — строго старые фолды, замороженный перенос — только ProofNet→Putnam. Putnam OOF в N9b не обязателен и отдельно помечается при отсутствии; N7 Putnam OOF обязателен.
Метаданные miniF2F Kimina восстанавливаются из сохранённых AST observer/token span файлов, без генерации или нового Lean replay. Используется отдельный supplement, старые манифесты не меняются.
Для PLS rank выбирается по conditional prefix NLL скалярной калибровки (ridge=.01, фиксировано до supervised результатов). Сравнения scalar additions совместно выбирают rank/направление и ridge по inner NLL; наружные labels не используются. Logit на z использует единственный train RMS масштаб по всем координатам, сохраняя геометрию в пространстве z. Grid=[.0001,.001,.01,.1,1,10]. Mean amplitude grid=[0,.25,.5,1].
Tie rule при совпадении inner NLL в пределах1e-10: последний ключ в фиксированном лексикографическом порядке. Для frozen параметры выбираются по среднему inner NLL5 source outer folds, как в no-length серии; full-source refit не использует Putnam labels.
PLS на бинарной метке использует deflation и orthonormal span; rank больше численного доступного сообщается как усечённый actual_rank. Никаких пост-отказных меток корректности: supervised directions только pre+at. Полные кандидаты после отказа допустимы в отдельной conditional задаче нахождения first-error, как в исходной серии; это не labels accepted/rejected для этих шагов.
