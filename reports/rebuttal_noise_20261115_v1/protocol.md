## Общие определения
Первый формальный отказ f сохранён с нуля; в отчёте t*=f+1. X — состояние после последнего токена тактики, X0 — formal-entry. xi_t=X_t-X_(t-1); z=Sigma^(-1/2)(xi-mu), w=||z||2. Слой 14 DeepSeek, 17 Goedel/Kimina, shrinkage .1, fold0. Для N1 m=log(w), строго положительные конечные w, без log1p/подмены нулей. Отбеливание и метки в калибровке независимы от оценочных исходов.
Самый ранний argmax при равенстве. После f нет принятых/отвергнутых обучающих меток; весь последующий путь допустим для ретроспективных описательных максимумов и явно оговорённой модельной калибровки.
Основные веса: равные задачи/exercise groups, равные попытки внутри задачи. Для статистик шагов дополнительно равные шаги внутри выбранной части попытки. Вторичные: равные попытки (и равные шаги внутри попытки). Сохраняются также исходные шаговые описательные суммы. Ресэмплинг целых групп, одинаковые bootstrap multiplicities для сравниваемых методов. Не объединять датасеты. Нет интервалов при <20 целевых групп, для C2 дополнительно <20 групп доноров.
Основные T=.6 популяции совпадают с Table1 loaders common_v2.score_frames/records: 528/448/324 miniF2F DeepSeek/Goedel/Kimina и 456/262 ProofNet DeepSeek/Goedel неудачных попыток. Для T=1 miniF2F — сохранённые NNG_B3_v2 (544/456/498). Когорты локализаторов могут отличаться из-за L>=2; различия явно фиксируются, никогда не смешиваются под одним знаменателем. Сохранённые веса/фолды старых локализаторов воспроизводятся при их сравнении.

## Prefix / C2
Основной prefix: неудачи t*>=2, earliest argmax среди 1..t* равен t*. Uniform = 1/t*. Полная prefix доля и prefix на поддержке C2 обе публикуются.
C2: у попыток с t*>s берётся тот же record-indicator на 1..s. Средние доноров вычисляются отдельно для каждого точного s; затем стандартизуются к распределению t* целевых попыток. Для равных групп донорские попытки сначала усредняются внутри группы при данном s, затем между группами. Целевые попытки усредняются внутри группы после ограничения поддержкой. При отсутствии доноров длина исключается; исключённые N/доля публикуются. Поддержка, донорские средние и веса пересчитываются в каждом bootstrap. Проверяем совместимость с engine.py repair_v1.
Вариант без первого кандидата по буквальному заданию: t*>=2, кандидаты 2..L / 2..t*. При t*=2 prefix механически равен 1 (один кандидат); C2 также равен 1 на срезе2. Это выделяется в отчёте. Дополнительно историческая чувствительность t*>=3; не заменяет основной вариант.
Seeds: базовый 2026111501 плюс стабильные индексы блоков/ячеек/реплик; никакого отбора seed. Все случайные числа и конфигурации сохраняются.

## N4
Восемь Table1 ячеек, J earliest global argmax; доли J<t*, J=t*, J>t*. Оба веса, 10000 групповых bootstrap. Проверка точной H1 без порога: она требует P(J<t*)=0. Этот результат не проверяет всю шумовую H1'.

## N1
Пять T=.6 ячеек. Fold0 и fold1 сохранённые преобразования на непересекающихся калибровочных задачах; сверить fit_task_ids и отсутствие пересечения. Восстановить обе нормы на одних векторах, сверить fold0 с архивом. В первую очередь префиксы до отказа включительно; весь путь отдельная чувствительность.
R = взвешенная Pearson corr(logw0,logw1); within R после вычитания среднего по попытке. sigma_e² = .5 Var(demeaned(logw0-logw1)). Уровень дисперсии и веса фиксируются как выше. Аналогичные описательные статистики по first/later, абсолютным позициям 1/2/3/4–5/6–10/11–24/25+, log(1+tokens), типу тактики (10 самых частых + OTHER; частотный выбор не по исходу). Для длины — взвешенная корреляция разности и её квадрата; для категорий — среднее/дисперсия/группы. Нельзя интерпретировать разность только как независимый гомоскедастичный шум: общая калибровочная смещённость/зависимость не оценивается.
Прямое усреднение mbar=(m0+m1)/2: обе prefix и C2, парный bootstrap.
SIMEX: lambda=[0,.5,1,1.5,2], 200 независимых нормальных массивов по шагам. Одна реализация шума у исходной попытки используется для всех её целевых/контрольных срезов. Common random numbers между lambda и bootstrap для снижения Монте-Карло погрешности; bootstrap условен на этот фиксированный MC банк, sigma_e переоценивается в каждой из 2000 групповых реплик, все ранги, поддержка и C2 пересчитываются. Обе весовые схемы имеют собственную sigma и собственную экстраполяцию. Повторные копии bootstrap группы используют ту же исходную траекторию/MC шум (кластерная схема).
Точки — средние статистик по MC; квадратичная OLS по пяти lambda основная, линейная чувствительность; предсказание в -1 без ограничения [0,1]. Сохраняются 2000 реплик, число конечных значений и MC стандартная ошибка. Отдельная sigma first/later всегда как заранее заданная чувствительность (не выбирается по p-value); для группирования используется within-остаток общей попытки.
Объяснённый разрыв (p(-1)-p0)/(1-p0), если p0<1. Если верх95CI p(-1)<.9, оценённого шума отбеливания недостаточно для точной связи. Это одна компонента, не подтверждение/опровержение H1' в целом. Отрицательные/неустойчивые экстраполяции сообщаются как есть, результаты не клипуются.

## N9a
Полные приращения miniF2F всех3, ProofNet/Putnam двух моделей, если доступны. Fold0 eigenbasis по убыванию собственных значений, полосы 1–16,17–256,257–1024,1025–4096, omit1–16. Норма в полосе. Сохранённые ненулевые eigenvectors ортонормированы; нулевое вырожденное подпространство при нехватке ранга дополняется детерминированным full QR (фиксированная библиотека/версия, знаки diagR положительные). Внутри численно вырожденной полосы базис не уникален: от этого зависят разделённые полосы; данное ограничение явно указывается, альтернативный базис по исходу не подбирается. Если full4096 недоступно, ячейка не считается.
Метрики: global exact, +-1, full prefix, C2-supported prefix/control/contrast; вариант без первого кандидата и отдельная историческая t*>=3. Парные 10000 bootstrap.
Подтверждающая семья: 5 альтернатив × 2 метрики (global exact, C2 prefix contrast) × все доступные ячейки, основной вариант с первым кандидатом и основные group веса. Вторичные веса/без первого — описательные чувствительности. Holm p вычисляется по парному bootstrap с центрированием на наблюдаемой разности, двусторонне, плюс1. Интервалы: обращение step-down Holm сравнений векторных нулевых гипотез при фиксированных остальных гипотезах = ранговые Holm-интервалы не обеспечивают простого совместного покрытия; поэтому для решения используем консервативные simultaneous Bonferroni интервалы 1-.05/M вместе с точным Holm p, явно называем их консервативными по отношению к Holm, а не выдаём за обычные95CI. Задание о Holm-интервале реализуется этим более строгим критерием, а не постфактум выбором ранга. Обычные95CI также публикуются.
Сигнал в конкретной полосе заявляется только при положительном контрасте против fullnorm и исключении0 консервативным интервалом в обеих ProofNet ячейках и Holm p<.05. Иначе формулировка: «полосы, выбранные без меток, не концентрируют сигнал» с пояснением, что это отсутствие установленной концентрации по заданному критерию, а не доказательство эквивалентности.

## N9b / N9c
Сохранённые outer5/inner3 групповые фолды серии локализаторов. Основной ProofNet OOF и frozen ProofNet→Putnam (настройки только ProofNet), дополнительно Putnam OOF для сопоставимости если ресурсов достаточно, с явным статусом. Обучение только на принятых шагах до f и первом отказе, без postfailure negatives.
1. Среднее по попыткам z_f - mean(z_<f), с равными групповыми весами; исключаются f=0 из обучения этой разности, нормировка направления. Shrinkage amplitude a in [0,.25,.5,1] выбирается по inner conditional NLL префикса; ненулевая амплитуда не меняет argmax, это явно объясняется.
2. Векторный conditional logit на префиксах, ridge из той же сохранённой сетки серии; скалярных metadata нет.
3. Weighted PLS с бинарной меткой first-failure против accepted-prefix; rank [1,4,16,64], веса равные groups/attempts/steps. Сохранённый orthonormal span, центрирование только train, projection score ||Pz|| без вычитания class centroids. Выбор k по inner conditional NLL после однопараметрической калибровки norm. PLS выбран вместо бинарного LDA, у которого единственное дискриминантное направление.
На heldout подписанный и абсолютный score для1/2; projection norm для3. Те же метрики и bootstrap как N9a; без первого обязательно. Для scalar добавок log1p(abs(score)) или log1p(norm) к PSC,MD; в N9c Goedel PST,MD_noN. В каждом inner fold заново fit направления на innertrain, joint selection direction/ridge only inner NLL, затем outertrain refit, outertest не используется. Сравнения с log1p(w) и MD_increment по тем же heldout задачам; доля захваченного векторного выигрыша только при положительном знаменателе, иначе NA. Основной обученный способ — mean difference; другие вторичные. Нет выбора лучшего по test.
Высокая точность обученной проекции означает информацию о метке на других задачах, не независимую оценку шума, не причинность и не «направление ошибки».
