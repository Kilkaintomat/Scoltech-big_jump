# A3: p-value precision, fixed before any held-out comparisons
The primary family has540 tests and the exploratory family is larger. With a plus-one Monte Carlo p from only10000 draws, its minimum1/10001 exceeds the first primary Holm boundary0.05/540. This would make primary rejection impossible for a purely numerical reason. Interval resampling MUST remain10000 as requested, and neither family nor endpoints are reduced.
Before ANY held-out score/localizer/detection file or contrast result exists, fix p-values as two-sided, asymptotic cluster-bootstrap-SE t tests: se = sample SD of the10000 centered/fixed-prediction task bootstrap contrasts; t = observed contrast/se, degrees of freedom = contributing independent task groups minus1. For C2 use min(target,donor task counts). For AUROC use the minimum count of task groups contributing each outcome. Missing support (<20), insufficient finite draws or undefined contrast => p=1. A zero-SE nonzero contrast uses the two-sided sign bound min(1,2^(1-G)); a zero contrast uses p=1.
Individual95% intervals remain the prescribed percentile task-bootstrap intervals. Holm uses these continuous p-values with the already frozen540-primary and separate exploratory families. These are approximate asymptotic tests, NOT exact finite-sample randomization p-values; report this explicitly. No claim of exact FWER beyond the marginal-test approximation.
The original centered-Monte-Carlo p is retained in the metric as p_mc_10000 for audit, alongside bootstrap SE, degrees of freedom and method. No folds, grids, features, populations, training procedures or effect-selection rules change. This resolves Monte Carlo resolution before observing any comparison, not a response to an effect.
