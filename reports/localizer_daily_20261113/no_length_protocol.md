# Goedel без длины тактики

Исследовательская абляция после изучения прежних результатов. Удаляется только признак log(1+число токенов тактики), вместе со всеми его сплайн-столбцами. Все коэффициенты и регуляризация переобучаются. Тип тактики, позиция и surprisal сохраняются. Это не запрет всем остальным признакам косвенно коррелировать с длиной.

Два baseline: PST = позиция + surprisal + тип; MD_noN = PST + знаковая и абсолютная соседняя разность surprisal. Для каждого: без добавки; +W; +raw deltaX; +u. W = log(1+норма whitened приращения); raw deltaX = X_t-X_{t-1}; u = единичное направление whitened приращения. Whitening фиксирован по исходной независимой calibration; стандартизация координат обучается только на train.

Шесть условий: ретроспективные ProofNet OOF, ProofNet→Putnam frozen и Putnam OOF; три соответствующих streaming-условия. Всего 8 вариантов × (5+1+5) × 2 = 176 внешних/full-source fits и 48 полных ячеек. Приоритет очереди — ProofNet offline для прямого ответа на вопрос.

ProofNet offline использует исторические общие разбиения lean_localizer_20260925_v1. Замороженный offline перенос выбирает lambda по среднему inner-NLL пяти внешних обучений, как исторические абляции. Putnam offline и streaming используют те же сохранённые разбиения, что localizer_putnam_stream_20261113_v1. Nested CV 5 внешних/3 внутренних разбиения по задачам; общий lambda grid 0.0001,0.001,0.01,0.1,1,10; выбор по NLL, при равенстве более сильная регуляризация. Все попытки одной задачи остаются вместе.

Ретроспективная условная softmax выбирает первый отказ среди всех сохранённых тактик, включая суффикс после него; рассматривает только попытки с отказом и L>=2. Сохраняются t/L и индикатор последнего шага: удаление длины тактики не означает удаления длины всего доказательства.

Streaming — бинарный hazard текущего завершённого шага при заданных архивных AST-границах; после первого отказа строки не используются. Нет конечной длины, будущих признаков и метки отказа на входе. Тип сохранённого AST не доказывает реализованность online-парсера. Порог калибруется по inner OOF: на ProofNet по verified-траекториям; на Putnam, где нет verified, по принятым префиксам до отказа. Номинальные 5/10/20%; основной показанный порог 10%. Реальный FPR на test публикуется отдельно, на Putnam verified FPR отсутствует.

Каждая задача имеет одинаковый вес, попытки внутри неё одинаковый вес; в streaming каждый шаг внутри попытки имеет одинаковый вес. Основные контрасты +W и +raw deltaX против своего baseline: 2 добавки × 2 baseline × 6 условий = 24 сравнения отдельно для попадания и NLL. +u — дополнительный описательный вариант, его интервалы также показываются. Bootstrap 10000 задач по парным фиксированным OOF/frozen предсказаниям; не включает переобучение, минимум 20 групп для интервала; Holm24 внутри основной семьи. Незавершённые ячейки не усредняются.

Проверки до запуска: отсутствие влияния числа токенов на train preprocessing и test design; префиксная инвариантность streaming; разделение групп и покрытие всех отложенных попыток; воспроизведение сохранённого PST по его коэффициентам; конечность и малый градиент обученных fits. Новые PST ProofNet fits дополнительно сверяются с прежними предсказаниями. Source hash зафиксирован до производства; входы/выходы получают манифесты. Старые задачи и результаты не изменяются.
