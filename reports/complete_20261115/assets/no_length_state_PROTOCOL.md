# Полное состояние Goedel без длины тактики

Дополнение запрошено после просмотра прежней абляции. Её 176/176 fits завершены; полного состояния X в исходном списке вариантов не было. Новая серия сохраняет старые результаты.

Новые варианты: PST_state = позиция + surprisal + тип тактики + X_t; MD_noN_state дополнительно содержит знаковую и абсолютную соседнюю разность surprisal. X_t — исходное 4096-мерное состояние после блока на последнем токене текущей тактики, не приращение и не нормированный вектор. Координаты стандартизируются только по train. Удаляется явный log(1+число токенов тактики) вместе со сплайн-столбцами. Косвенные корреляции состояния и типа с длиной не удаляются.

Два варианта × (ProofNet OOF 5 фолдов + Putnam OOF 5 фолдов + замороженный перенос ProofNet→Putnam 1 fit) × (offline и stream) = 44 новых внешних/full-source fits и 12 ячеек. Cohort, внешние и внутренние разбиения, веса, lambda grid и оптимизатор идентичны прежней абляции. Каждый OOF fit содержит 3 внутренних фолда и 6 lambda; frozen offline выбирает lambda по среднему inner-NLL пяти внешних fits нового варианта. Приоритет — ProofNet offline.

Основной вопрос дополнения: PST_state−PST на ProofNet OOF offline. Hit = точный выбор первого отказа среди всех сохранённых шагов ошибочного доказательства с L>=2. NLL = минус логарифм вероятности первого отказа. Streaming оценивает текущий шаг до первого отказа включительно; будущих шагов, итоговой длины и f в признаках нет. Порог выбирается только по inner OOF, основной номинальный уровень 10%; фактический FPR публикуется. Putnam без verified не позволяет оценить verified FPR.

Бейзлайны и W/deltaX/u берутся из неизменённых предсказаний прежней серии. Проверяются хэши, совпадение ID и групп. Для 12 новых контрастов X против своего baseline: парные bootstrap интервалы по задачам, 10000 повторов, фиксированные модели, seed 20261113. Менее 20 групп — без CI. Holm12 отдельно для NLL и Hit/Exact; старый Holm24 не меняется. FPR и изменение добавочного эффекта при исключении длины — описательные дополнительные контрасты с собственными CI.

Сравнение с длиной и без неё производится только для совместимых предсказаний на одной популяции с теми же разбиениями и остальными признаками; PST не подменяется MD. Положительный результат новой проверки сам по себе не доказывает причинное объяснение прежнего ухудшения.

До запуска: независимость design и переобученного preprocessing от tokens; префиксная инвариантность streaming; групповая изоляция и полное покрытие; воспроизведение исторического PST; сходимость. Код замораживается до fits; каждый результат содержит manifest с версиями, входами и хэшами.
