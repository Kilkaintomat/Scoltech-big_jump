# Verification repair and independent P3 diagnosis

Original completions, token IDs, protocol bytes, source snapshots, failed journals and
manifests are retained. New verification, extraction and P1-P3 analysis have their own
immutable lineage. Still-running generation jobs are external dependencies: the replacement
graph cannot resample answers.

The pinned Lean ContextInfo.runCoreM uses withOptions after constructing a default Core.Context.
This updates the visible option but not the active maxHeartbeats field. The REPL repair derives
that active field from ContextInfo.options when creating each ProofSnapshot. A tactic-level
set_option wrapper was tested and rejected because it leaves the actual limit unchanged.
The separately built binary, original source, two local patches and build environment are
sealed under runs/repl_runtime_20260912_sealed and pinned by configs/repl_runtime.json.
Header import errors are propagated before the frontend discards header diagnostics.
The startup guard and bounded retries remain; repeated failure still prevents all labelling.
 Delimiter
continuation retains same-indentation closing lines, while comments, strings, character
literals and quoted identifiers cannot open a delimiter group. Original source offsets
remain the measurement boundaries.

Lean heartbeat and recursion exhaustion are resource timeouts. Whole-proof and replay
verdicts remain visible. Known resource differences are explicitly explained; disagreements
without a known resource or hole cause continue to block downstream work. The protocol's
heartbeat and wall-clock budgets are unchanged. Startup checks require functioning standard,
Mathlib and explicitly imported Aesop tactics. Startup alone may be retried a fixed number
of times before any sample is processed; failures remain in diagnostic provenance.

The P3 diagnosis tests an interaction between estimated calibration thresholds and the
lower support of simulated failure values. When the estimated threshold is below that
support, excesses have a positive lower endpoint and a zero-location GPD is misspecified
at that threshold. This does not excuse undercoverage: it identifies a condition the full
analysis procedure must handle or explicitly limit its inference to avoid.

The independent protocol is runs/p3_diagnosis_20260912/protocol.json. It compares estimated
and known-support thresholds and percentile and basic task-bootstrap intervals, under
original support, lower support and an exponential null. The oracle threshold is unavailable
for model data. Independent calibration and evaluation task arrays, new seeds and the
original sample sufficiency rules are used. Omitting unrelated P1/P2 variables changes the
RNG stream but preserves the P3 marginal experiment. No correction is promoted automatically,
no q is changed, and this calibration cannot alone validate inference for transformer data.

Run IDs, measured results and limitations are recorded under audit/revision_2026_09_12.
